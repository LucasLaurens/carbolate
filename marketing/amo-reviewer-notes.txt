BUILD
The add-on is bundled with Vite. carbolate-sources.zip is a git archive of the tagged commit v2.0.0.

Environment used: macOS, Node.js 25.2.1, npm 11.6.2 (CI builds the same commit on Ubuntu with Node 25).

  npm ci
  npm run build:firefox

The build writes the add-on to dist/; its contents match carbolate-firefox.zip. dist/manifest.json is generated by scripts/build.mjs from scripts/manifest.mjs.

NETWORK AND DATA
The add-on makes no network request of any kind. A test (src/security/no-network-egress.test.ts) scans the sources and the built bundle for every request API and fails the build if one appears. Measurements stay in storage.local, hence data_collection_permissions: { required: ["none"] }.

PERMISSIONS
- storage, unlimitedStorage: the measurements, kept locally for the history window the user picks ("keep everything" would hit the 10 MB cap otherwise)
- alarms: the daily reset at midnight
- downloads: the CSV export the user triggers
- content script on <all_urls>: reads the Performance API timings of each visited page; no page content, form, cookie or keystroke is read

VALIDATOR WARNINGS
The two UNSAFE_VAR_ASSIGNMENT warnings (innerHTML in side_panel.js) come from React DOM, bundled as a dependency. The add-on's own code never assigns innerHTML.

The panel opens as a sidebar (sidebar_action). Firefox 140 is the minimum because it is the first release that reads data_collection_permissions.
