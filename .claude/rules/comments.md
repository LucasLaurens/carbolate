# Commentaires

- Un commentaire explique le **pourquoi**, jamais le **quoi** — le code dit déjà ce qu'il fait.
- Supprimer tout commentaire qui paraphrase le code.
- Pas de blocs commentés laissés dans le code.
- Pas de `// TODO` sans ticket associé ni date.
- JSDoc/TSDoc réservés aux interfaces publiques exposées à d'autres modules.
