# Glossary / Glossaire

Shared vocabulary for Carbolate. This file is the **single home** for the meaning
of a term: code identifiers, UI strings and other docs defer to it.

Vocabulaire partagé de Carbolate. Ce fichier est le **domicile unique** du sens
d'un terme : les identifiants du code, les libellés UI et les autres docs s'y
réfèrent.

## How to read the Status column / Lire la colonne Statut

| Status       | Meaning                                                            | Sens                                                                      |
| ------------ | ------------------------------------------------------------------ | ------------------------------------------------------------------------- |
| **live**     | Implemented and shipped                                            | Implémenté, en production                                                 |
| **decided**  | Decision taken, code not written yet — see the linked ADR          | Décision prise, code non écrit — voir l'ADR liée                          |
| **excluded** | Deliberately outside the model; listed so nobody assumes otherwise | Volontairement hors modèle ; listé pour que personne ne suppose l'inverse |

A **decided** term must not be treated as describing current behaviour. When the
code catches up, flip the row to **live** in the same commit.

Un terme **decided** ne décrit pas le comportement actuel. Quand le code
rattrape, passer la ligne à **live** dans le même commit.

## 1. Measurement units / Unités de mesure

| ---------------------- | ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Page visit**         | Visite de page            | One navigation to one URL, keyed `(tabId, timeOrigin, url, observedFrom)`. The atomic unit of measurement. Navigating five pages in one tab produces five page visits, and reloading one page adds another. Replaces the former `MetricTab`, which was one entry per browser tab id and silently overwrote itself on each navigation. Stored as `PageVisit`, in `DailyRecord.visits`. — Une navigation vers une URL, clé `(tabId, timeOrigin, url, observedFrom)`. Unité atomique de mesure. Matches the CSV row count exactly. — La statistique affichée : combien de chargements le jour a enregistrés. Pas « pages visitées » — trois F5 font trois chargements. | **Daily record**       | Enregistrement journalier | Everything measured on one **local** calendar day: the day's page visits plus their aggregated totals. | **Transferred data**   | Données transférées       | Bytes that actually crossed the network, compressed, as reported by `PerformanceResourceTiming.transferSize`. **Not** the page weight, **not** the uncompressed size. A resource served from cache reports `0`. — Octets réellement passés sur le réseau, compressés. **Pas** le poids de la page, **pas** la taille décompressée. Une ressource en cache vaut `0`.                                                                                                                                                                                                         | live                                                                                                                                                                                              |
| **Page weight**        | Poids de la page          | Uncompressed size of everything a page loads (`decodedBodySize`). Larger than transferred data and **never** used for the carbon figure — only to compute avoided CO₂. — Taille décompressée. Supérieure aux données transférées, **jamais** utilisée pour le chiffre carbone.                                                                                                                                                                                                                                                                                              | live — [ADR](decisions/2026-08-05-perimetre-modele-carbone.md)                                                                                                                                    |
| **Request**            | Requête                   | One entry of `performance.getEntriesByType("resource")`. Counts sub-resources, not navigations. — Une entrée de `getEntriesByType("resource")`. Compte les sous-ressources, pas les navigations.                                                                                                                                                                                                                                                                                                                                                                            | live                                                                                                                                                                                              |
| **Page load duration** | Durée de chargement       | `PerformanceNavigationTiming.duration` — **wall-clock** time from navigation start to load end, in seconds. Formerly misnamed `cpuTimeToLoad`: it never measured CPU. Used as a **proxy** for device activity. — Temps **mural**, pas du CPU. Ancien nom trompeur : `cpuTimeToLoad`. Sert de **proxy** d'activité appareil.                                                                                                                                                                                                                                                 | live — [ADR](decisions/2026-08-05-perimetre-modele-carbone.md)                                                                                                                                    |
| **Screen time**        | Temps d'écran             | Cumulated seconds a page visit spent visible, from `visibilitychange`. The input of screen CO₂ and the only honest way to charge long-lived pages. — Secondes cumulées pendant lesquelles la visite était visible.                                                                                                                                                                                                                                                                                                                                                          | decided — [ADR](decisions/2026-08-05-perimetre-modele-carbone.md)                                                                                                                                 |

### Byte units / Unités d'octets

**Base 10 everywhere** — `1 MB = 10⁶ bytes`, `1 GB = 10⁹ bytes`. This matches
every published carbon source (`kWh/GB` figures are base 10) and matches
`CARBON_PER_GB`. Base-2 units (MiB, GiB) are **not** used anywhere, in code, UI
or docs.

**Base 10 partout.** Aligné sur les sources carbone publiées et sur
`CARBON_PER_GB`. Les unités base 2 (MiB, GiB) ne sont utilisées nulle part.

**live.** Every conversion goes through `src/utils/bytes.ts`, and
`src/utils/bytes.test.ts` fails if a base-2 constant reappears. Before this rule
was encoded, the code divided by `1024²` while labelling the result `MB` — a
4.9 % error between the stored value and its own label.
See [ADR](decisions/2026-08-05-unites-et-retention.md).

## 2. Carbon model / Modèle carbone

| ------------------------- | -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| **gCO₂e**                 | gCO₂e                                  | Grams of CO₂ equivalent — the single output unit of the whole app. Never grams of CO₂ alone; the "e" carries the other greenhouse gases converted to their CO₂ warming equivalent. — Grammes équivalent CO₂, unité de sortie unique.                                                                                                                                                                                                   | live                                                           |
| **Grid carbon intensity** | Intensité carbone du réseau électrique | gCO₂e emitted per kWh of electricity consumed. `GRID_INTENSITY_G_CO2_PER_KWH = 442` (global average, IEA 2023). Turns every energy figure into a carbon figure. — gCO₂e émis par kWh consommé. Convertit toute énergie en carbone.                                                                                                                                                                                                     | live                                                           |
| **Emission factor**       | Facteur d'émission                     | A constant converting an activity into gCO₂e (`CARBON_PER_GB`, `DEVICE_FACTOR`…). Every factor must carry its source or be labelled as a house estimate. — Constante convertissant une activité en gCO₂e. Tout facteur porte sa source, ou est étiqueté comme estimation maison.                                                                                                                                                       | live                                                           |
| **Contribution source**   | Source de contribution                 | A pluggable emission channel implementing `CarbonContributionSource`. Adding one does not modify `CarbonCalculator` (OCP). — Canal d'émission enfichable. En ajouter un ne modifie pas `CarbonCalculator`.                                                                                                                                                                                                                             | live                                                           |
| **Network CO₂**           | CO₂ réseau                             | Emissions of transmission networks **and** data centres, derived from transferred data. `CARBON_PER_GB = 176.8` = `0.4 kWh/GB × 442 gCO₂e/kWh`. — Émissions des réseaux **et** des datacenters, dérivées des données transférées.                                                                                                                                                                                                      | live                                                           |
| **Device CO₂**            | CO₂ appareil                           | The CPU and GPU of the user's machine during page load. `DEVICE_FACTOR = 0.00098` — a **house estimate**: 8.0 W, what remains once the sourced 3.4 W panel is taken out of the 11.40 W the former single factor implied. Nothing publishes that 8 W. — CPU et GPU de la machine pendant le chargement. Estimation maison : 8,0 W, le reste une fois la dalle sourcée retirée.                                                          | live — [ADR](decisions/2026-09-15-energie-ecran.md)            |
| **Screen CO₂**            | CO₂ écran                              | The screen's share, `SCREEN_FACTOR = 0.00042` — 3.4 W of panel draw (Fraunhofer/DOE parc average) × 442 gCO₂e/kWh. An **attributional allocation**, not an avoidable emission. Charged on the time the page was **visible**, never on the load duration, which would bill that window twice. A tab never looked at is charged none of it. — Part de l'écran, 3,4 W sourcés. Allocation attributionnelle facturée sur le temps visible. | live — [ADR](decisions/2026-09-15-energie-ecran.md)            |
| **Avoided CO₂**           | CO₂ évité                              | What the cache saved: `decodedBodySize` of cache-served resources × `CARBON_PER_GB`. A positive, pedagogical figure — never subtracted from the total. — Ce que le cache a économisé. Chiffre positif et pédagogique, jamais soustrait du total.                                                                                                                                                                                       | live — [ADR](decisions/2026-08-05-perimetre-modele-carbone.md) |
| **Perimeter**             | Périmètre                              | What the model counts and what it leaves out. Carbolate is **usage-only**. — Ce que le modèle compte et ce qu'il laisse dehors. Carbolate est en **usage seulement**.                                                                                                                                                                                                                                                                  | live                                                           |
| **Usage-only**            | Usage seulement                        | Only energy consumed **while browsing**: network, data centre, device. Manufacturing of servers, network gear and the user's device is excluded. Consequence: the figure is a **floor**, not a total — roughly 20–25 % below a full-perimeter model such as Sustainable Web Design. — Seule l'énergie consommée **pendant** la navigation. La fabrication est exclue. Conséquence : le chiffre est un **plancher**, pas un total.      | live                                                           |

## 3. Attribution / Attribution

| Term (EN)                    | Terme (FR)                  | Definition / Définition                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Status                                              |
| ---------------------------- | --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| **Domain**                   | Domaine                     | Host of the **visited page**, from `parseDomain()`. Never the host that served a given byte. — Hôte de la **page visitée**, jamais celui qui a servi un octet donné.                                                                                                                                                                                                                                                                                                            | live                                                |
| **Editorial attribution**    | Attribution éditoriale      | All bytes a page loads are charged to that page's domain, third-party included. A site loading forty trackers carries their cost — that is the point. — Tous les octets chargés par une page sont imputés à son domaine, tiers inclus. Un site qui charge quarante traceurs en porte le coût.                                                                                                                                                                                   | live                                                |
| **Registrable domain**       | Domaine enregistrable       | Last two labels of a host, with a short exception list (`co.uk`, `com.br`, `co.jp`, `com.au`…). A house heuristic, **not** a Public Suffix List: wrong on exotic suffixes, and a bundled PSL would cost ~80 KB in an extension whose subject is web weight. — Heuristique maison, **pas** une Public Suffix List. Fausse sur les suffixes exotiques.                                                                                                                            | live — [ADR](decisions/2026-09-15-poids-tiers.md)   |
| **First-party**              | Premier                     | A resource whose registrable domain equals the page's. — Ressource dont le domaine enregistrable est celui de la page.                                                                                                                                                                                                                                                                                                                                                          | live — [ADR](decisions/2026-09-15-poids-tiers.md)   |
| **Third-party**              | Tiers                       | Any other resource: ads, trackers, external CDNs — and an in-house CDN on a different registrable domain, which the heuristic cannot tell apart. — Toute autre ressource. Un CDN maison sur un autre domaine enregistrable est compté tiers, l'heuristique ne sait pas les distinguer.                                                                                                                                                                                          | live — [ADR](decisions/2026-09-15-poids-tiers.md)   |
| **Attributional allocation** | Allocation attributionnelle | A share of energy something else already spends, charged to browsing because browsing uses it — `screenCo2`. Distinct from an avoidable emission: closing the tab does not turn the panel off, so the figure must never be read as a saving. — Part d'une énergie déjà dépensée, imputée à la navigation parce qu'elle s'en sert. Fermer l'onglet n'éteint pas la dalle.                                                                                                        | live — [ADR](decisions/2026-09-15-energie-ecran.md) |
| **Third-party weight**       | Poids tiers                 | Share of a page visit's **requests** that came from third parties — not a share of its bytes. A cross-origin resource whose server omits `Timing-Allow-Origin` reports a size of zero, and only ~25 % of third-party requests carry it, so a byte share would under-report the most opaque trackers. "41 of 78 requests on this site are third-party." — Part des **requêtes** d'une visite venant de tiers, jamais des octets : une ressource opaque déclare une taille nulle. | live — [ADR](decisions/2026-09-15-poids-tiers.md)   |

## Naming rules / Règles de nommage

1. **A code identifier uses the EN term of this glossary.** No synonyms: not
   `tab` for a page visit, not `size` for transferred data, not `cpuTime` for a
   wall-clock duration.
   _Un identifiant de code reprend le terme EN de ce glossaire. Pas de synonymes._
2. **A UI string uses the FR/EN pair of this glossary**, via `src/i18n/`.
   Translation keys derive from the EN term — never a French key in an English
   identifier. The sobriety keys were `"sobre" | "modere" | "intensif" | "excessif"`;
   they are now `SobrietyLevel` (`"sober" | "moderate" | "intensive" | "excessive"`),
   defined once in `src/carbon/sobriety.ts` and indexed by `Translations`, so the
   French lives only on the translation side.
   _Les clés i18n dérivent du terme EN — jamais une clé française dans un
   identifiant anglais._
3. **A term whose meaning changes is edited here first**, then in the code, in
   the same commit. A stale definition is worse than a missing one.
   _Un terme dont le sens change est modifié ici d'abord, puis dans le code,
   dans le même commit._
4. **Every emission factor carries either a source or the label "house
   estimate".** An unsourced constant presented as sourced is the one defect
   that discredits the whole app.
   _Tout facteur d'émission porte soit une source, soit la mention « estimation
   maison »._
